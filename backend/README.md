# RiskLens AI Backend

FastAPI backend for a synthetic-data payment risk detection prototype.

## Commands

```bash
pip install -r requirements.txt
python train.py
python evaluate.py
pytest -q
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

Swagger/OpenAPI docs are available at `http://127.0.0.1:8000/docs` when the server is running.

## Notes

The model is trained on synthetic transaction data generated by `train.py`. This backend is a hackathon prototype and is not a production fraud detection system.
